# Code of conduct

We want this project to be rigorous, welcoming, and unusually clear about
uncertainty.

Participants must:

- discuss people and work with respect;
- criticize statements, proofs, APIs, and evidence—not contributors;
- state provenance, assumptions, and confidence honestly;
- give credit for mathematical, formalization, review, and tool work;
- accept that a compiled proof may still need API or exposition changes;
- avoid harassment, discrimination, intimidation, and unwanted attention.

Maintainers may edit or remove contributions and comments that violate these
standards, and may temporarily or permanently restrict participation. Report
conduct concerns privately through the contact route on the maintainer's
GitHub profile. Reports will be handled as confidentially as practical.
